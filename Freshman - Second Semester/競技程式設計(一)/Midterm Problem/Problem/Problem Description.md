## D. 合作無間 (Perfect Cooperation)
### Description
在NYCU的CP課程中，由於有些題目相當具備挑戰性，因此同學們決定與其他人私下合作，共同尋找某些題目的解法，其中，如果能讓某些人都是實質上的合作夥伴，那麼我們稱這一群人達成了完美合作 (Perfect Cooperation)。

舉例來說: 如果同學0與同學1進行合作，而同學1又與同學2進行合作，那麼由同學0\~2所組成的學生群就達成了完美合作；然而，如果同學0僅與同學2進行合作，而同學1僅與同學2進行合作，那麼，僅由同學0\~1所組成的學生群並"沒有"達成完美合作。(因為還要加入同學2才能使同學0與同學1具有實質合作關係) 由於同學數量眾多，因此，老師只打算統計從同學0到同學i為止，所組成的小群體間的關係，是否有達成完美合作。

Notice: 已有合作關係的人們依舊可以繼續建立多次關係，甚至是跟自己合作!
### Input Format
第一行有兩個正整數n,m，分別代表學生人數與合作關係數。 接下來的m行，每行有兩個正整數A,B，代表同學A與同學B兩人進行合作。
### Output Format
輸出一行由Y與N組成的字串，其中第i項代表由同學0到同學i之間所組成的合作關係，其中，使用Y代表達成完美合作，N代表不完全合作。
### Specification
1<=n,m<=5*10^6
0<=A,B<n
Hint: I/O Optimization
