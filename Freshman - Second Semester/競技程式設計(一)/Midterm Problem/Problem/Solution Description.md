Perfect Cooperation 解答
===
本文介紹如何解決「Perfect Cooperation」。題目要求統計從同學 0 到同學 i 的子群是否達到「完美合作」——也就是說，子群內所有同學必須透過直接或間接合作關係形成連通圖。接下來我們將詳細說明本題的思路、數據結構與具體實作細節。

## 題目概要

在 NYCU 的 CP 課程中，因為部分題目極具挑戰性，同學們會私下合作。如果一群同學之間能夠互相連通，則稱這群同學達成了「完美合作」。
例如：
- 同學 0 與同學 1 合作，則群 {0,1} 達成完美合作。
- 如果同學 0 與同學 2 合作，而同學 1 也與同學 2 合作，則只有群 {0,1,2} 才達成完美合作；僅看 {0,1} 不成立，因為 0 與 1 的合作是透過 2 才連通的。

題目要求對每個前綴子群 {0, 1, …, i}，判斷是否構成連通圖，輸出一個由 ```Y``` 和 ```N``` 組成的字串，其中 Y 表示連通（達成完美合作），N 表示不連通。

## 解題思路

本題可轉化為「動態連通性」的判斷問題。隨著節點從 0 到 n-1 依次加入，我們需要知道當前子群是否形成單一連通分量。經典方法是使用 並查集（Disjoint Set Union, DSU） 結構來處理：
- **初始化**：每個同學一開始自成一集。
- **邊的合併**：當遇到一個合作關係（邊）時，對應兩個同學所在集合進行合併。
- **動態查詢**：每次加入一個新節點時，我們將該節點以及其所有合作關係（在題目規定下，只考慮與當前編號不大於 i 的邊）合併，再檢查是否所有已加入的節點都屬於同一集合。

為了提高 DSU 的效率，本題標準解使用了 路徑壓縮 與 按集合大小合併（union by size）。這樣的組合使得 DSU 操作的攤銷時間複雜度接近 O(α(n))，在題目規模很大時依然能夠高效運行。

## 核心數據結構與函式

### DSU 數組
- p[]：父節點陣列，p[i] 表示 i 的父節點。
- sz[]：集合大小陣列，sz[i] 表示以 i 為根的集合中節點個數。
- root：全局變數，用來記錄包含節點 0 的集合的代表節點。每次合併後都更新為 f(0)。

### find 函式：f(x)
此函式使用路徑壓縮來加速查找：

```cpp
int f(int x){ //x^y 在這裡與x!=y的功能相同，只是位元操作速度稍快
    return x ^ p[x] ? p[x] = f(p[x]) : x;
}
```
- 當 x 不是自己的父節點時，遞迴查找 p[x] 的代表元，同時將 p[x] 直接更新為根節點，達到扁平化作用。

### union 函式：uni(x, y)

```cpp
void uni(int x,int y){
    x = f(x); 
    y = f(y);
    if(sz[y] < sz[x])
        swap(x, y);
    if(x ^ y){ //x^y 在這裡與x!=y的功能相同，只是位元操作速度稍快
        sz[y] += sz[x];
        p[x] = y;
    }
    root = f(0);
    return;
}
```
- 先分別取得 x 與 y 的代表元。
- 判斷哪一個集合較小，然後將較小集合合併到較大集合上（若 sz[y] < sz[x]，則交換 x 與 y）。
- 更新合併後的集合大小，並將較小集合的根的父節點設為較大集合的根。
- 每次合併後，通過 root = f(0) 保持全局變數 root 為包含節點 0 的集合的正確代表元。

## 主程式流程

### 1. 初始化與讀入數據：
- 從輸入讀取節點數 n 與邊數 m。
- 初始化 DSU 結構，將每個節點設為獨立集合，大小均為 1。
### 2. 邊的儲存：
- 讀取每條邊。題目規定，若兩個節點中較大的數字作為索引，則將較小數字的邊加入對應的圖中：
```cpp
if(u > v)
    Graph[u].push_back(v);
else
    Graph[v].push_back(u);
```
- 這樣儲存可以保證：在處理節點 i 時，所有儲存在 Graph[i] 中的邊，其另一個端點必定小於 i，符合「只用已加入的節點 union」的要求。
### 3. 逐步動態查詢：
- 對於每個 i 從 0 到 n-1：
    1. 遍歷 Graph[i] 中的所有邊，調用 uni(i, Graph[i][j]) 進行合併。
    2. 將當前節點 i 推入隊列 q。
    3. 循環從queue中取出節點，若其代表元等於 root 則 pop 掉，直到queue為空或遇到不屬於 root的節點。
    4. 如果queue最終為空，則表示從 0 到 i 的所有節點均屬於同一集合（即完美合作），輸出 Y；否則輸出 N。

## 時間與空間複雜度

### - 時間複雜度：
DSU 的 union 與 find 操作在使用路徑壓縮及按集合大小合併的情況下，攤銷複雜度為 O(α(n))，其中 α(n) 為反 Ackermann 函數，非常緩慢增長，幾乎可視作常數。因此總體時間接近 O(mα(n))。
### - 空間複雜度：
主要使用了三個陣列：p[]、sz[]、Graph[]，以及一個隊列 q。對於 n、m 最高可達 5×10^6 的情況，空間使用在可接受範圍內，整體空間複雜度為O(m)。
